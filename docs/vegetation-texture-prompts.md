# Vegetation texture expansion

Generated using the built-in imagegen tool. New source assets for the world vegetation pass; the original files are retained. Actual returned dimensions are validated by the runtime loader. Transparent PNG alpha is preserved. The browser packs the seven grass/flower sources into an atlas and bakes normal maps, alpha-aware mipmaps, and relightable grass-patch LODs.
